# 原始计算图算子排布模式分析

本文档记录对 `artifacts/data/case_001.json` 到 `case_100.json` 的原始计算图画像分析。分析目标是按算子排布模式对输入图分型，便于后续实验分层、算法诊断和论文描述。

## 分析口径

原始计算图采用二部图形式存储：

- `ops`：算子节点，包含 `id`、`op`、`pipe`、`cycles`；
- `tensors`：张量节点，包含 `id`、`pos`、`size`；
- `edges`：连接 `op -> tensor` 或 `tensor -> op`。

分析时先将二部图折叠为 op-DAG：若存在 `op_a -> tensor_t -> op_b`，则视为 `op_a -> op_b` 的计算依赖。随后提取以下特征：

- 算子占比：`MATMUL`、`CONV`、`ADD`、`RELU`、`REDUCE`、`SUB`、`DIV`、`MUL`、`EXP`、`SIGMOID` 等；
- 拓扑形态：op-DAG 深度、最大层宽、分支节点比例、汇合节点比例；
- 排布 motif：长链、宽浅并行块、卷积残差块、attention/归一化式子图等。

## 七类细分

使用算子占比、宽深形态、分支/汇合比例做标准化特征后，`KMeans` 聚类在 `K=7` 时具有较好的可解释性。轮廓系数随 `K` 的变化如下：

| K | silhouette | 类别规模 |
|---:|---:|---|
| 3 | 0.343 | 38 / 32 / 30 |
| 4 | 0.420 | 30 / 30 / 25 / 15 |
| 5 | 0.448 | 30 / 27 / 25 / 15 / 3 |
| 6 | 0.467 | 25 / 25 / 22 / 15 / 10 / 3 |
| 7 | 0.494 | 25 / 25 / 22 / 12 / 10 / 3 / 3 |
| 8 | 0.512 | 25 / 25 / 22 / 12 / 7 / 3 / 3 / 3 |
| 9 | 0.516 | 25 / 25 / 22 / 12 / 5 / 3 / 3 / 2 / 3 |

虽然 `K=8/9` 的数值略高，但会把少数异常形态继续拆碎；`K=7` 在统计稳定性和人工命名之间更均衡。

## 四类粗粒度归并

写论文或报告时，可以将七类进一步归并成四类，以降低叙述复杂度：

| 粗类 | 包含细类 | 说明 |
|---|---|---|
| 矩阵主导类 | 2、4、7 | 以 `MATMUL` 为核心，包含宽浅矩阵块、gated MLP 和 MatMul-Add 批处理 |
| 卷积残差类 | 3 | 以 `CONV/RELU/ADD` 为核心，呈 CNN 或 residual block 形态 |
| Attention/归一化复杂链类 | 5 | 包含 `SUB/EXP/REDUCE/DIV/MATMUL`，拓扑更深且分支汇合多 |
| 小型混合与极深链类 | 1、6 | 一类是中小规模混合图，另一类是极窄超深串行链 |

实际实验分析中，建议使用七类作为分层统计口径；在正文叙述中使用四类概括总体规律。
